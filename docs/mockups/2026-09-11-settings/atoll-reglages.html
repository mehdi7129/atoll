Autonomie de Claude Code

Niveau

Atoll n'approuve aucune demande automatiquement.

Rockstar est actif pour Claude Code. Les demandes sont approuvées automatiquement et les règles deny sont suspendues.

Auto-approbations3 · exemple
Ce que change Rockstar

Atoll approuve les autorisations Claude, y compris destructrices, et répond aux questions et aux plans.

Les règles deny de Claude sont mises de côté jusqu'à la sortie de ce mode, même si Atoll est fermé. Les sessions déjà ouvertes doivent être reprises pour relire ces règles. Tes autres hooks bloquants restent actifs.

Codex

Les autorisations de Codex se règlent dans son terminal. Rockstar ne s'y applique pas.
